Direction A: Ruled notebook

A literal school notebook. Every screen is a ruled page: blue rules every 28px set the line height of all running text, and a red double margin line runs from the header to the tab bar. Lessons and decks are index cards laid on the page. Buttons are ballpoint ink, and the highlighter swipes behind what matters: the active tab, key numbers and key terms. Dark mode is the same notebook at night: graphite-blue paper, faint rules, warm off-white ink.

Honest risks

  • The 28px rhythm is fragile: any stray 1px border or odd padding knocks text off the rules. The build needs a rule-gap discipline (rows sized in rules; borders become inset shadows).
  • Ruled text costs some reading comfort, because descenders cross the rules. The reader uses fainter rules; if that's still too busy, keep rules only in lists and leave the reading column plain (that's Direction B's choice).
  • The margin takes 32px of a 380px screen (316px for text, about the same as the current reader's 2px rule plus padding).
